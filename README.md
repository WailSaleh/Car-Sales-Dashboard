# 🚗 Car Sales Dashboard

> An interactive Streamlit web application for exploring car sales advertisements through dynamic visualizations and exploratory data analysis.

---

# 📖 Project Overview

Interactive dashboards help users explore data quickly and uncover meaningful insights. This project demonstrates the development and deployment of a Streamlit web application that visualizes vehicle sales advertisements using interactive charts.

The application allows users to generate visualizations that support exploratory data analysis and better understand the distribution of vehicle listings.

# 📂 Dataset

The application uses a dataset containing vehicle advertisement information, including attributes commonly used for exploratory data analysis and visualization.

> **Note:** The dataset included in this repository is provided for educational and portfolio purposes.

# 🎯 Project Objectives

The objectives of this project were to:

- Develop an interactive web application using Streamlit.
- Perform exploratory data analysis (EDA).
- Visualize the distribution of vehicle advertisements.
- Enable users to generate interactive charts.
- Deploy the application for public access.
